# Zahra Matcha — موقع الطلبات

موقع طلبات زهرة ماتشا: منيو، تخصيص المشروبات، استلام أو توصيل (القطيف • سيهات)، دفع بالتحويل مع رفع الإيصال، تتبع الطلب، بطاقة ولاء، وشاشة تحضير.
تصميم وتطوير: نرجس العمري

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` + `app.js` | صفحة العميل |
| `staff.html` | شاشة التحضير، تدخلها بالرمز (`رمز شاشة التحضير` من الإعدادات) |
| `style.css` | التصميم |
| `config.js` | رابط النظام `API_URL` |
| `data.js` | منيو احتياطي يظهر لين ما يتم الربط |
| `apps-script/Code.gs` | الباك إند (Google Sheets + Apps Script) |
| `img/` | الصور، واسم الصورة يُكتب في عمود "الصورة" في الشيت |

## التشغيل
1. **Google Sheet:** من حساب زهرة ماتشا، أنشئ Sheet جديد، وبعدين Extensions ← Apps Script. الصق `apps-script/Code.gs` واحفظ.
2. شغّل الدالة `setup` ووافق على الصلاحيات. تنشأ الأوراق: المنيو، الخيارات، مناطق التوصيل، الإعدادات، الطلبات، بطاقة الولاء. ويطلع رمز شاشة التحضير في الـ Log.
3. **Deploy ← New deployment ← Web app**، وخلّ Execute as: **Me** و Who has access: **Anyone**. انسخ الرابط.
4. حط الرابط في `config.js` داخل `API_URL` وارفع التعديل.
5. **Cloudflare Pages:** Create project ← Connect to Git ← `zahra-site`. بدون Build command، والـ Output directory: `/`.
6. عبّ في ورقة **الإعدادات**: اسم البنك، الآيبان، اسم صاحب الحساب، مكان الاستلام.

> أي تعديل على `Code.gs` بعد النشر يحتاج: Deploy ← Manage deployments ← Edit ← **New version**.

## الإدارة اليومية من الشيت
- **المنيو:** تعدّل فيه الاسم والسعر والوصف والصورة. خانة "متوفر" إذا صارت `لا` يظهر الصنف للعملاء "نفدت الكمية". الأقسام تظهر في الموقع بنفس ترتيبها في الشيت. لا تغيّر عمود "المعرّف".
- **الخيارات:** الحليب، الحلاوة، إضافات الماتشا، خيارات الكوكيز. عمود "لا يظهر مع" فيه معرّفات الأصناف اللي ما يظهر معها الخيار.
- **الإعدادات:** تفتح وتقفل الطلبات، وتحدد الأوقات وبيانات البنك وعدد أختام الولاء، وتقدر تكتب تنبيه يظهر أعلى الصفحة.
- **الطلبات:** كل طلب ينضاف سطر، والإيصال يكون رابط في Drive داخل مجلد "إيصالات زهرة ماتشا". الحالة تتغير من شاشة التحضير أو من الشيت.
- **بطاقة الولاء:** كل مشروب من الأقسام المحددة في الإعدادات يحسب ختم. إذا وصل العميل للعدد المحدد، يقدر يستخدم مشروب مجاني يُخصم فيه أرخص مشروب في طلبه.
